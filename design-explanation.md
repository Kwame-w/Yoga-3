# Touchstone 3 Design Explanation - Riverbend Yoga Studio

## Client Alignment

Riverbend Yoga Studio wants its site to feel calm, welcoming, and accessible to beginners, busy professionals, and older adults, so I kept the design simple, uncluttered, and easy to scan. Every page shares the same header, navigation, and footer, so visitors always know where they are and can reach classes, the schedule, or the request form in one tap. On the Classes and Pricing page, each class type (Gentle Flow, Vinyasa, Restorative, Chair Yoga, Lunchtime Express Flow) sits in its own card with a bold title and a fern-green top border, which lets a first-time visitor compare options quickly. The weekly schedule and pricing tables use a dark forest-green header row and lightly striped rows so times and prices are easy to follow. On the Workshops and Events page, the request form uses large inputs (at least 2.8rem tall) with bold labels, which is easier for older adults and for anyone filling it out on a phone.

## Color Palette

I used four main colors, stored as CSS variables so they stay consistent on every page: Forest green (#203D35), Fern green (#638575), Coral (#A64932), and Mist (#F1F6F2). The greens reflect nature and calm, which fits a yoga studio, while the warm coral adds a small, friendly accent without feeling loud. Forest green is used for all body text, navigation links, table headers, buttons, and the footer, and it has about a 10.8:1 contrast ratio on the Mist background, which is well above the 4.5:1 WCAG guideline. Coral (5.3:1 on Mist) is reserved for highlights such as the short accent bar under each page title, link hover states, keyboard focus outlines, and the border beside the home page "Our Mission" section. Fern is only used for decorative details such as card top borders, input borders, and radio buttons, so it never carries body text.

## Typography

I used a two-font pair: Georgia (a serif) for headings and Trebuchet MS (a sans-serif) for body text, navigation, and form controls. Georgia gives the page titles and section headings a warm, editorial feel that matches the studio's welcoming tone, while Trebuchet MS stays clear and readable at smaller sizes, especially on phones. I created hierarchy mainly through size and weight: the main h1 is 3.2rem on desktop (2.2rem on mobile), section h2 headings are 2rem, and card h3 headings are 1.1rem and bold. Body text is 1rem with a relaxed 1.65 line height, and navigation links are bold (700) so they stand out from regular text. Both fonts are web-safe and set as CSS variables (--display-font and --body-font), so they are applied the same way across all four pages.

## Responsive Design

I built the stylesheet mobile-first: the base CSS styles the phone layout, and two min-width media queries (768px and 1024px) add layout changes for larger screens. On a phone, the header is a Flexbox column, with the logo stacked above the navigation links, which wrap onto a second line; at 768px and up, the header switches to flex-direction: row with the logo on the left and the navigation on the right. The class cards on the Classes and Pricing page use Flexbox with flex-wrap: they are one card per row on mobile, two per row at 768px, and three per row at 1024px. On the home page, the "Our Mission" section stacks the heading, photo, and text in one column on phones, then places the text beside the photo on larger screens. Spacing also grows with the screen: the h1 increases from 2.2rem to 3.2rem and the main content padding increases from 2rem to 3.5rem, while wide tables scroll sideways on small screens instead of breaking the page width.

## Design Challenge

My biggest challenge was that my first version of the stylesheet was desktop-first: it used max-width media queries to shrink the layout down for phones, which did not match the mobile-first requirement. To fix it, I moved the phone layout (stacked header, single-column cards, smaller headings, scrolling tables) into the base styles and rewrote the media queries as min-width: 768px and min-width: 1024px so they only add the multi-column layouts for bigger screens. While testing at 375px, I also noticed the "Home" link sat higher than the other navigation links, because a general li + li margin rule was also adding space to the navigation list items. I added a more specific nav li + li { margin-top: 0; } rule, and the links lined up evenly. I then checked every page at phone and desktop widths to confirm the layout, colors, and links all worked.
